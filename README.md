# 科研潜力实验室

一个手机优先的科研人格娱乐测评网页初版。

## 当前版本

- 纯 HTML / CSS / JavaScript，无构建工具，直接部署到 GitHub Pages 即可。
- 6 道科研情景题，第一题支持一次换题；换题按钮只在场景确认页出现，进入第一道选择题后会消失。
- 目前包含 6 个荒诞科研场景：野狗、电动离心机、食堂颠勺、窗外鸽子、流转咖啡杯、神秘打印机。
- 每次测试从当前场景的专属题库抽 2 题，再从公共科研题库抽 4 题；公共题目和专属题目都会随机变化。
- 评分维度：创新性、前沿性、可行性、抗导师打击。
- 包含「究极摆烂的科研观测员」和「实验室永动机·卷王」两个隐藏人格。
- 结果分享按钮在手机端调用系统分享；桌面端复制文案和链接。
- 当前统计保存到浏览器 localStorage，仅用于本地演示，不是真实后台数据。

## 本地预览

直接双击 `index.html`，或在项目目录启动一个静态服务器：

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000。
