# 科研潜力实验室 ✦

**来测测你的科研潜力吧。**

把熟悉的科研日常，变成一场不太正经的问答冒险。面对荒诞的选题、突如其来的组会和导师的灵魂追问，你会如何接招？

👉 **[点击开始测试](https://wqh12.github.io/research-potential-lab/)**

## 怎么玩

1. 点击“开始测试”，进入一个随机科研现场。
2. 凭直觉选择最像你的反应。
3. 领取你的专属结果，把它发给科研搭子。

手机、平板和电脑都可以玩，无需登录。每次遇到的题目和选项都可能不同，没见过的结果，留给你自己发现。

## 记录和隐私

- 无需注册，不要求姓名、手机号、照片或学校信息。
- 本机记录包含测试次数、已解锁结果、最近记录和分享操作，可在右上角查看、导出或清除。
- 未启用全站统计时，只显示本机记录。
- 启用全站统计后，会发送匿名随机设备标识、访问来源、交互事件及题目/选项编号，用于统计整体使用情况；不会发送自由文本或私人资料。匿名设备数不等于真实人数。
- 清除浏览器数据会重置本机记录和匿名标识；清除本机记录不会删除已计入全站的匿名汇总。

## 有点子？

欢迎在 [Issues](https://github.com/WQH12/research-potential-lab/issues) 分享新的荒诞现场、逆天选项，或反馈手机显示问题。反馈问题时，可以附上场景、机型和截图。

**纯属娱乐，不是心理量表，不评价真实科研能力。**
